# dizziee.power-profiles

Power profile switcher for the Omarchy bar. Switch between power-saver, balanced, and performance profiles with a popup panel.

## Requirements

- `powerprofilesctl` (usually pre-installed on desktop Linux)

## Installation

```sh
git clone https://github.com/JJDizz1L/dizziee.power-profiles.git ~/.config/omarchy/plugins/dizziee.power-profiles
```

Then enable **Power Profiles** in the Omarchy bar widget settings.

## Configuration

No configurable options.
